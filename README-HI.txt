SOCIAL NEWS — FREE STARTER WEBSITE
===================================

FILES
- index.html: Main responsive Hindi-first website
- style.css: Design and responsive styles
- script.js: Search, theme toggle, browser-only bookmarks, calculator
- privacy.html and terms.html: Draft policy pages (edit before publishing)

IMPORTANT LIMITATIONS
- This is a static front-end starter, not a complete live-news platform.
- Headlines shown are sample informational cards, not a live news feed.
- Live TV is a placeholder. Only embed streams you own or have permission to show.
- Bookmarks and theme preference are saved in the current browser only.
- No login, admin panel, push notifications, database, real-time news API, or ad revenue system is connected yet.
- Do not publish sample or unverified claims as current news.
- Replace the example contact email and review the privacy/terms pages before launch.

FREE PUBLISHING (GITHUB PAGES)
1. Sign in or create an account at https://github.com/
2. Create a new public repository named social-news-website.
3. Upload index.html, style.css, script.js, privacy.html and terms.html to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for deployment. GitHub will show the website URL in Settings > Pages.
8. Test on your phone and correct any issues.

FREE PUBLISHING (NETLIFY DROP)
1. Visit https://app.netlify.com/drop
2. Sign in if asked.
3. Upload the unzipped folder containing the files.
4. Netlify will provide a public preview URL. Rename the site in site settings if the name is available.

NEXT STEPS FOR A REAL PRODUCTION SITE
1. Connect a legitimate news API or create an editorial workflow/admin panel.
2. Add a database and secure authentication only if user accounts are needed.
3. Configure official live video embed links.
4. Add analytics and cookie/privacy disclosures where required.
5. Apply for ad services only after the site has original, useful content and meets the provider's policies.
6. Verify copyright permissions and fact-check every news item.
